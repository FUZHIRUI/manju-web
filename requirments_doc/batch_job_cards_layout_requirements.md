# 需求文档：Batch 页面任务卡片布局优化

## 1. 需求概述

### 1.1 背景
用户反馈 Batch 页面（`?project=xxx&tab=batch`）的任务卡片栏渲染效果不佳，原因是任务卡片采用竖向排列，视觉效果不如横向排列美观。

### 1.2 目标
将任务卡片从竖向排列改为横向排列，通过横向滚轮滚动展示，提升页面视觉美观度。

---

## 2. EARS 需求分析

### 2.1 功能需求

| ID | Event | Actor | Request | Scope |
|----|-------|-------|---------|-------|
| FR-001 | 用户访问 Batch 页面 | 系统 | 显示横向排列的任务卡片 | 任务状态区域 |
| FR-003 | 任务卡片内容 | 系统 | 保持原有信息展示 | 每个任务卡片 |

### 2.2 非功能需求

| ID | 类型 | 描述 |
|----|------|------|
| NFR-001 | 可用性 | 横向布局支持滚轮滚动展示 |
| NFR-002 | 兼容性 | 不影响现有任务卡片的功能（点击、展开、状态显示等） |
| NFR-003 | 性能 | 布局变更不影响页面渲染性能 |

---

## 3. 影响评估

### 3.1 影响范围

| 文件 | 影响类型 | 影响程度 |
|------|----------|----------|
| `frontend/style.css` | CSS 样式修改 | 中 |
| `frontend/app.js` | 无需修改 | 无 |
| `frontend/index.html` | 无需修改 | 无 |

### 3.2 兼容性分析

- **现有功能**: 任务卡片的点击、展开、状态显示等功能不受影响
- **滚动交互**: 支持横向滚轮滚动查看更多卡片
- **动画效果**: 运行中任务的呼吸动画需要保持

---

## 4. 验收标准

| ID | 验收条件 |
|----|----------|
| AC-001 | 任务卡片横向排列显示 |
| AC-002 | 卡片之间有适当间距 |
| AC-003 | 卡片宽度固定或自适应 |
| AC-004 | 支持横向滚轮滚动查看更多卡片 |
| AC-005 | 运行中任务的动画效果正常 |
| AC-006 | 不同状态（success/error/running）的样式正常显示 |

---

## 5. 约束条件

- 仅修改 CSS 样式，不修改 JavaScript 逻辑
- 保持现有的 HTML 结构不变
- 保持现有的功能特性不变
